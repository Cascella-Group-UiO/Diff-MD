## Commands Used To Assemble The Export Tree

These commands were run from the original workspace root. They created a fresh `export_github/` directory and copied only the public export surface.

```bash
cd /home/orlandi/Project_Diff-MD/Diff-MD-regret/Diff-MD-regret

rm -rf export_github
mkdir -p export_github

rsync -a \
  --exclude='*.code-workspace' \
  --exclude='__pycache__' \
  --exclude='*.pyc' \
  src/ export_github/src/

cp README.md OPTIMIZE.md TRAIN.md pyproject.toml setup.py requirements.txt LICENSE export_github/

rsync -a \
  --exclude='__pycache__' \
  --exclude='*.pyc' \
  --exclude='*.code-workspace' \
  --exclude='CLAUDE.md' \
  --exclude='*claude*' \
  examples/ export_github/examples/

rsync -a \
  --exclude='build/' \
  --exclude='gmx2hymd/' \
  --exclude='*.egg-info/' \
  --exclude='__pycache__' \
  --exclude='*.pyc' \
  --exclude='*.code-workspace' \
  --exclude='memory.md' \
  --exclude='*claude*' \
  gmx2hymd/ export_github/gmx2hymd/
```

The `gmx2hymd/gmx2hymd/` directory was intentionally excluded because it was a checked-in virtual environment, not source code.

## Pre-Push Checks

Before creating the online repository, run:

```bash
cd /home/orlandi/Project_Diff-MD/Diff-MD-regret/Diff-MD-regret/export_github

git status --short
git log --oneline --decorate -5
git remote -v

git ls-files -z | xargs -0 -I{} du -b "{}" | sort -nr | head -20
```

Expected before adding the GitHub remote:

- `git status --short` should be empty after committing this file.
- `git remote -v` should print nothing.
- No tracked file should be larger than 100 MB for a normal GitHub push.

## Create The GitHub Repository Online

Create an empty repository on GitHub first. Do not initialize it with a README, `.gitignore`, or license, because this local repository already has those files.

Use one of the following publishing paths.

## Option A: Push With SSH

Replace `YOUR_GITHUB_USERNAME` and `YOUR_REPO_NAME`.

```bash
cd /home/orlandi/Project_Diff-MD/Diff-MD-regret/Diff-MD-regret/export_github

git branch -M main
git remote add origin git@github.com:YOUR_GITHUB_USERNAME/YOUR_REPO_NAME.git
git push -u origin main
```

If you prefer to keep the branch named `master`, use this instead:

```bash
cd /home/orlandi/Project_Diff-MD/Diff-MD-regret/Diff-MD-regret/export_github

git remote add origin git@github.com:YOUR_GITHUB_USERNAME/YOUR_REPO_NAME.git
git push -u origin master
```

## Option B: Push With HTTPS

Replace `YOUR_GITHUB_USERNAME` and `YOUR_REPO_NAME`.

```bash
cd /home/orlandi/Project_Diff-MD/Diff-MD-regret/Diff-MD-regret/export_github

git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/YOUR_REPO_NAME.git
git push -u origin main
```

If `origin` already exists and points to the wrong URL, replace it:

```bash
git remote set-url origin https://github.com/YOUR_GITHUB_USERNAME/YOUR_REPO_NAME.git
git push -u origin main
```

## Option C: Create And Push With GitHub CLI

This option requires the `gh` command-line tool.

```bash
cd /home/orlandi/Project_Diff-MD/Diff-MD-regret/Diff-MD-regret/export_github

gh auth login
git branch -M main
gh repo create YOUR_GITHUB_USERNAME/YOUR_REPO_NAME \
  --private \
  --source=. \
  --remote=origin \
  --push
```

For a public repository, replace `--private` with `--public`.

## Verify The Online Push

After pushing, run:

```bash
cd /home/orlandi/Project_Diff-MD/Diff-MD-regret/Diff-MD-regret/export_github

git remote -v
git status --short
git ls-remote --heads origin
```

Expected result:

- `origin` should point to the GitHub repository URL.
- `git status --short` should be empty.
- `git ls-remote --heads origin` should show the pushed branch.

## If GitHub Rejects A Large File Later

The current export was checked and did not contain a tracked file above 100 MB. If future exported trajectories or archives exceed that limit, use Git LFS before pushing those files:

```bash
cd /home/orlandi/Project_Diff-MD/Diff-MD-regret/Diff-MD-regret/export_github

git lfs install
git lfs track '*.h5'
git lfs track '*.xtc'
git lfs track '*.trr'
git add .gitattributes
git add -A
git commit -m 'Track large simulation artifacts with Git LFS'
git push
```
