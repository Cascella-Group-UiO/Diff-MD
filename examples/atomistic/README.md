# Minimal atomistic example

This folder provides a tiny converter-friendly atomistic setup with GROMACS/ITP-like bonded rows.

## Files
- `topol.toml`: system + include list
- `TEST.toml`: molecule definition with bonds, angles, proper dihedrals, and impropers
- `options.toml`: NVT runtime settings with `atomistic_ff.ff_family = "amber_like"`
- `input.h5`: coordinate file (generated by script/snippet)

## Bonded row formats
- Angles: `[i, j, k, funct, theta0_deg, k]`
- Proper dihedrals: `[i, j, k, l, funct, phi0_deg, k, multiplicity]`
- Improper dihedrals in `dihedrals`: `[i, j, k, l, 2, phi0_deg, k]`
- Improper dihedrals in `impropers`: `[i, j, k, l, phi0_deg, k]`
